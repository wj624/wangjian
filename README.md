# 王健的代码库

一套基于 **TradingView Pine Script v6** 引擎开发的高级定制化交易指标工具箱。

它将**全球宏观经济数据、跨国流动性水位、债务周期模型**与**微观技术动能**相结合，为长周期价值投资与中短期对冲套利提供严密的沙盘推演与决策支持。

## 🧭 三层工作流

```
┌─ 第 1 层：宏观定方向 ────────────────────────────────┐
│  AA流动性压力指数        → 美元体系水温 / 系统性风险 │
│  AA国家债务经济数据分析   → 目标国债务周期位置          │
│  AA对冲套利风险          → 跨国套利真实成本            │
└────────────────────────────────────────────────┘
                    ↓ 发出预警后
┌─ 第 2 层：中期 / 远期精对 ──────────────────────────┐
│  BBB 宏观全景 V7.9       → 3–12 个月货币商业周期     │
│  BBB 达利欧看板 V26      → 1–10 年主权债务长波       │
└────────────────────────────────────────────────┘
                    ↓ 方向确认后
┌─ 第 3 层：微观择时 ────────────────────────────────┐
│  AA情绪观察基础版        → 背离 / 极值共振 / 量能    │
│  AA波段分布图           → 筹码 POC + AVWAP + 计划    │
│  BBB 订单流 + 三层云图    → Delta / 结构状态         │
│  BBB VW-KDJ            → 量价加权极值拐点          │
└────────────────────────────────────────────────┘
```

**核心原则：宏观决定做不做，微观决定什么时候做。**

## ⚙️ 技术特性

| 项目 | 说明 |
|---|---|
| 底层语言 | **Pine Script v6** 全量标准 |
| 数据源 | `FRED:`、`ECONOMICS:`、`TVC:`、`COMEX:`、`FX_IDC:`、`INDEX:` |
| 防重绘 | 宏观数据请求统一 `lookahead=barmerge.lookahead_off` |
| 缺失值处理 | `ta.valuewhen` 前向填充（粘值） |
| 请求上限 | Pine 限制 `request.security` ≤ 40 次 |

---

## ⚠️ 重要提示

1. **宏观数据为低频序列**：FRED / ECONOMICS 多为周 / 月 / 季频，在日线图上会呈现**阶梯状粘值**，这是正常现象，不是数据错误。

2. **数据源可能失效**：三方数据源偶尔会调整口径或下线。若某序列失效，TradingView 会提示错误，可通过设置的「数据源」下拉框切换到备选源（如 `TVC:US02Y` ↔ `FRED:DGS2`）。

3. **付费方案要求**：部分 `ECONOMICS:` 序列在免费方案下可能返回空值。

4. **背离信号天然滞后**：依赖 `ta.pivotlow/pivothigh` 的背离需要右侧若干根 K 线确认，属算法固有特性。

5. **本仓库脚本仅用于研究与推演**，不构成任何投资建议。实盘决策请自行承担风险。
