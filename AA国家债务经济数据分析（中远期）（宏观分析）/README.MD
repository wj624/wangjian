# AA国家债务经济数据分析（中远期）（宏观分析）

> **Pine Script v6** · 副图指标
> 脚本声明：`indicator("国家债务经济数据分析（中远期）最终版", shorttitle="国家债务经济数据分析（中远期）最终版", overlay=false, max_lines_count=500, max_labels_count=500)`

---

## 一、这个指标解决什么问题

它是 **Ray Dalio《债务危机》框架的量化沙盘**，用于评估主要经济体的**长期债务健康度与去杠杆压力**。

脚本由**两大板块**组成：

| 板块 | 位置 | 作用 |
|---|---|---|
| **V26 走势图** | 副图曲线区 | 中美日欧四国的「利息压力指标」横向对比走势 |
| **V2.3 右侧看板** | 右上 8×8 表格 | 对**某一个选定国家**做深度诊断（债务 / 货币 / 通胀 / 信用 / 周期定位） |

**适用场景**：大类资产配置、国别风险比较、判断某国是否处于"负利差"债务死局。**不适合短线择时**。

## 三、核心计算逻辑（代码说明）

### 3.1 数据抓取与缺失值处理

```pine
f_get_macro(_tic) =>
    _raw   = request.security(_tic, "D", close, gaps=barmerge.gaps_off,
                              ignore_invalid_symbol=true,
                              lookahead=barmerge.lookahead_off)
    _fixed = ta.valuewhen(not na(_raw), _raw, 0)     // 前向填充
    _fixed
```

- `ignore_invalid_symbol=true` —— 无效符号不报错
- `ta.valuewhen` —— 宏观季 / 月频数据缺失时**粘值**，避免曲线断裂

月线数据走 `sec(sym, expr) = request.security(sym, "1M", expr, lookahead=barmerge.lookahead_off)`。

### 3.2 两种计算模式

```pine
f_calc_val(_mode, _debt, _yield, _gdp) =>
    _mode == "模式A…" ? (_gdp - _yield)                 // 越高越好
                      : ((_debt / 100) * _yield)        // 越低越好
```

**模式A（动能与造血能力，g − i）**

```
val = 名义 GDP 同比增长率 − 10 年期国债收益率
```

> 正值 → 增长跑赢利率，具备"和谐去杠杆"的增长潜力；负值 → 利率反超增长，进入去杠杆压力。**小于 0 即不可持续。**

**模式B（底线与存量压力，代理利息负担）**

```
val = (债务率 ÷ 100) × 10 年期国债收益率
```

量纲为「占 GDP 的百分比」。例：债务率 250%、利率 4% → `2.5 × 4 = 10`。

### 3.3 五级严重度评分（0 优秀 ～ 4 危机）

**模式A（越高越好）**

| 条件 | base |
|---|---|
| `val > 3.0` | 0 |
| `val > 1.0` | 1 |
| `val > 0.0` | 2 |
| `val > −2.0` | 3 |
| 其他（`≤ −2.0`） | 4 |

**模式B（越低越好）**

| 条件 | base |
|---|---|
| `val < 1.5` | 0 |
| `val < 2.5` | 1 |
| `val < 3.5` | 2 |
| `val < 5.0` | 3 |
| 其他（`≥ 5.0`） | 4 |

**债务放大器 `debt_amp`（平滑调节因子）**

```pine
debt_amp = math.min(math.max(0.0, (_debt - 100.0) / 50.0), 2.0)
severity = math.min(base + debt_amp, 4.0)
```

即债务率每超过 100% 后，每增加 50 个百分点风险权重 +1，最高 +2。这体现了「债务存量放大利息冲击」的核心设定。

**再叠加债务增速斜率惩罚**：

```pine
debt_growth      = (当前债务率 − 12 个月前债务率) / 12 个月前债务率 × 100
debt_growth_slope= (debt_growth − 6 个月前 debt_growth) / 6.0
adjusted_severity= min(severity + (debt_growth_slope > 1 ? 1 : 0), 4)
```

### 3.4 总计利息压力（TP）

```pine
tp = debt × ((debt / 100) × yield)     // = debt² ÷ 100 × yield
```

例：债务率 250%、利率 1.5% → `250 × 3.75 = 937.5`。

**TP 分级**：

| 条件 | 颜色 | 含义 |
|---|---|---|
| `> 1200` | 红 | 必然发生债务螺旋（约 95% 危机概率） |
| `> 800` | 橙 | 高危风险 |
| `> 450` | 黄 | 压力增加 |
| `> 150` | 绿 | 正常健康 |
| `≤ 150` | 翠绿 | 极低风险 |

### 3.5 近期趋势（20 根回看，死区 ±0.1）

| 模式 | 改善 | 恶化 |
|---|---|---|
| A | `res > prev + 0.1` | `res < prev − 0.1` |
| B | `res < prev − 0.1`（取反） | `res > prev + 0.1`（取反） |

## 四、V2.3 单国深度分析指标

选定国家后，看板会计算以下中间量：

| 指标 | 公式 |
|---|---|
| M1/M2 剪刀差 | `M1同比 − M2同比`（同比窗口 = 12 根月线，封顶 ±40%） |
| 剪刀差动能 | `EMA(raw_scissors, 6 个月)`，再封顶 |
| 期限利差 | `10Y − 2Y` |
| 流动性溢价 | `10Y − M2同比` |
| 倒挂深度 | `ta.lowest(term_spread, 6 个月)` |
| 实际利率（CPI） | `10Y − CPI同比` |
| 实际利率（PPI） | `10Y − PPI同比`，看板称"企业生死线" |
| 铜金比 | `COMEX:HG1! / COMEX:GC1!`，与 EMA(10) 比较定风险偏好 |
| M1 环比动能 | `SMA(M1环比, 3 个月)`，领先 M1 同比约 6 个月 |
| 滞胀评分 | 见下 |
| 信用压力 | `月度变化 > 0.5%` 或 `信用利差 > 4.0%` |

**滞胀压力评分（满分 4）**：

| 项目 | 得分 |
|---|---|
| `PPI同比 > 2.0` | 1 |
| `PPI同比 − CPI同比 > 1.0`（传导不畅） | 1 |
| M2 同比下行（低于 3 个月前） | 1 |
| 期限利差 < 0（倒挂） | 1 |

≥`th_stagflation`（默认 3）触发滞胀预警。

**通胀类型四分类**：

| 条件 | 类型 |
|---|---|
| `PPI环比 > 0.2` 且 `CPI环比 < 0.1` | 成本推动型 |
| `CPI环比 > 0.1` 且 `PPI同比 ≥ 0` | 需求拉动型 |
| `PPI同比 < 0` 且 `CPI同比 < 1` | 通缩压力型 |
| 其他 | 结构均衡型 |

## 八、数据源清单

| 经济体 | 债务/GDP | 10Y 收益率 | 2Y 收益率 | 名义 GDP 同比 |
|---|---|---|---|---|

## 九、使用建议

1. **先粗后细**：先用 `view_mode = 总债务/GDP` 看四国债务率相对位置，再切到 `利息压力指标` 看偿付压力。
2. **模式 A 与模式 B 配合看**：模式 A 回答"增长能不能覆盖利息"，模式 B 回答"利息负担有多重"。两者背离时（如 A 好 B 差）通常意味着高增长高利率环境。
3. **看板「叠加信号」行是快速筛查入口**：滞胀预警 / 活钱回归 / 通缩共振 / 美元潮汐 / 信用恶化，五个标签一眼扫完。
4. **操作指引仅供参考**：脚本给出的是基于当前宏观状态的仓位倾向，实际执行仍需结合价格结构与个股基本面。

## 十、已知问题与限制

1. **信用利差硬编码为美国**：无论 `country` 选中国 / 日本 / 欧盟，信用利差恒为 `FRED:BAMLH0A0HYM2`。非美区域的"信用恶化"判定会失真。
2. **利率分位的标签与数据源不符**：看板中标注为「利率定位」的单元格，实际输出的是 **2 年期**收益率的 120 个月分位与均值（`rate_rank` / `rate_avg` 均基于 `y2_s`），不是 10 年期。
3. **欧盟用德国代理**：`TVC:DE10Y` / `TVC:DE02Y` 忽略了欧元区周边国家（意、希、法）利差，欧盟债务压力会被系统性低估。
4. **Security 请求接近上限**：约 38 次（见上文数据源说明）。
5. **时间有效性限制**：`is_valid_time()` 限制 `year >= 2000`，2000 年之前不渲染背景与看板。
6. **无告警函数**：脚本未声明 `alertcondition` 也未调用 `alert()`，**无法创建任何 TradingView 警报**。
7. **模式字符串依赖完整中文长串匹配**：`calc_mode` / `is_mode_A` 用完整中文字符串做精确相等比较，改动选项文案会导致静默失效。
8. **背景色顺序覆盖**：多个状态同时成立时，后绘制的覆盖先绘制的（最底层的「宏观风险背景」最后绘制，会盖住前面所有国家状态色）。
