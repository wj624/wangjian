## 一、这个指标解决什么问题

它是**跨国宏观套利的资金流向监控器**，透视华尔街"无风险套利"的真实成本。

传统教科书告诉你"把钱借给利率高的国家就能套利"，但忽略了三件事：**锁汇要花钱、主权债务有风险、汇率会反噬**。本脚本把这三件事全部量化：

1. **锁汇成本** —— 用抛补利率平价（CIP）框架，从 2 年期利差推算远期对冲的真实开销
2. **主权风险剥离** —— 目标国债务率超过安全线后，按 `债务惩罚因子` 直接扣减真实收益率
3. **裸敞口盈亏** —— 对没做对冲的"裸多头"，实时核算「利息收益 + 汇率损益」的总账

**适用场景**：在决定配置某国国债 / 权益 / 高息货币之前，先算清楚这笔跨国套利到底划不划算。

## 二、快速上手

### 第 1 步：加载

Pine 编辑器 → 新建空白指标 → 粘贴本目录同名代码文件 → **添加到图表**。

### 第 2 步：选目的地

加载后第一件事是设置 **`目标流入国家（目的地）`** 参数，可选：美国 / 日本 / 欧洲 / 中国。

这个开关会同时改变：
- 看板「宏观锚点」行显示的实时债务率与风险剥夺值
- 裸敞口监控使用的参考汇率
- 四条压力曲线中**哪一条被隐藏**（目的地自身不需要计算"流出压力"，会画 `na`）

### 第 3 步：读图

| 元素 | 含义 |
|---|---|
| 4 条彩色曲线 | 美/日/欧/中四国的「流向压力」时间序列 |
| 黄色横向带（0.5～1.5） | 风险预警区 |
| 红色横向带（1.5 以上） | 极端撤离区 |
| 背景色 | 宏观极端状态（紫＝流动性休克，红＝踩踏，蓝＝法币逃亡，橙＝利润反噬，绿＝利汇双击） |
| 右侧 7×10 看板 | 四国逐项数据 + 裸敞口状态 + AI 执行官裁决 |

## 三、核心计算逻辑（代码说明）

### 3.1 数据获取（防断层与防穿越）

```pine
f_secure_req(_ticker) =>
    float val = request.security(_ticker, timeframe.period, close,
                                 gaps=barmerge.gaps_off,
                                 lookahead=barmerge.lookahead_off,
                                 ignore_invalid_symbol=true)
    nz(ta.valuewhen(not na(val), val, 0), 0.0)
```

两个关键点：
- `lookahead=barmerge.lookahead_off` —— **杜绝未来函数/重绘**
- `ta.valuewhen(not na(val), val, 0)` —— 宏观数据缺失时**前向填充**（粘值），避免曲线断裂

债务数据走另一个函数 `f_get_econ`，固定请求 `"1D"`，并对每个国家提供**兜底默认值**（美 60 / 日 150 / 欧 70 / 中 83）。

### 3.2 主权风险惩罚（Debt Penalty）

```pine
raw_risk    = daf_k * math.max(0, debt_val - us_debt_threshold)
risk_penalty = use_risk_penalty ? raw_risk : 0.0
```

- `daf_k` ＝ 0.05（风险放大系数）
- `us_debt_threshold` ＝ 100.0（主权债务安全阈值 %）

**算例**：某国债务率 250% → `(250−100) × 0.05 = 7.5`，即每年被扣掉 **7.5 个百分点** 的风险溢价。

总开关 `use_risk_penalty` 关闭后惩罚归零，回归"传统华尔街无风险套利视角"。

### 3.3 CIP 对冲成本推演

```pine
f_calc_flow(_t_10y, _t_02y, _b_10y, _b_02y) =>
    float hedge_cost      = _b_02y - _t_02y          // 锁汇成本 = 目的国2Y − 本国2Y
    float raw_yield       = _b_10y - hedge_cost     // 名义收益 = 目的国10Y − 锁汇成本
    float risk_adj_yield  = raw_yield - risk_penalty// 风险调整后真实收益
    float severity        = _t_10y - risk_adj_yield // 流向压力 = 本国10Y − 真实收益
    [hedge_cost, risk_adj_yield, severity]
```

**判定标准**：

| severity | 状态 |
|---|---|
| < 0 | 🟢 **资金流入**（海外经风险调整后更划算） |
| 0 ～ 1.5 | 🟡 风险平仓（处于预警区） |
| ≥ 1.5 | 🔴 极端撤离（突破抛售线） |

### 3.4 裸敞口（未对冲多头）四季轮回

```pine
risk_adj_interest = b_10y - risk_penalty
unhedged_total    = risk_adj_interest + fx_mom
```

四个状态**互斥**：

| 状态 | 判定式 | 含义 |
|---|---|---|
| 🚨 恐慌踩踏 | `unhedged_total < 0` 且 `fx_mom ≤ −5%` | 利息收益被汇率暴跌彻底击穿，无差别抛售 |
| 🟠 利润反噬 | `unhedged_total < 0` 且 `fx_mom > −5%` | 白拿了利息，却被汇率吃掉全部利润 |
| 🟡 安全缓冲 | `fx_mom ≤ 0` 且 `unhedged_total ≥ 0` | 汇率小亏但利息覆盖得住 |
| 🟢 利汇双击 | `fx_mom > 0` 且 `unhedged_total ≥ 0` | 利息与汇率双向赚钱，多头狂欢 |

### 3.5 汇率动能的反向计价修正

```pine
dxy_mom = (dxy_val - dxy_prev) / dxy_prev * 100
eur_mom = (eur_val - eur_prev) / eur_prev * 100
jpy_mom = -((jpy_val - jpy_prev) / jpy_prev * 100)   // USD/JPY 反向计价
cny_mom = -((cny_val - cny_prev) / cny_prev * 100)  // USD/CNY 反向计价
```

> 💡 **为什么要取负号**：EURUSD 升值＝欧元强＝美元资产相对亏；而 USDJPY / USDCNY 升值＝日元 / 人民币弱＝美元买该国资产反而赚。取负号统一成"美元资金购买该国资产的汇率盈亏"。

### 3.6 美联储净流动性底座

```pine
net_liq_t    = fed_assets_t - tga_t - rrp_t     // 单位：万亿美元
is_liq_draining = net_liq_mom < -1.5            // 月度环比跌超 1.5%
```

## 五、AI 仲裁执行官（6 阶绝对优先级）

脚本内置一棵**执行级裁决树**，顺序不可调换，命中即返回：

| 优先级 | 条件 | 指令 |
|---|---|---|
| 👑 0 | `is_naked_shock` | 🚨【绝对防御】清仓所有波动资产，全仓超短端国债 / 逆回购吃息 |
| 👑 1 | `is_fiat_fleeing` | 🔥【抢筹硬资产】做空目标国长债，重仓黄金等零息硬通货 |
| 👑 2 | `is_stampede` | 🚨【踩踏预警】立即抽离未对冲头寸，警惕债汇双杀 |
| 👑 3 | `max_sev ≥ 1.5` 或 `is_profit_wiped` | ⚠️【资本大撤退】停止新增投资，逐步抛售目标国资产 |
| 👑 4 | `is_liq_draining` 或 `max_sev ≥ 0` | 🔔【逆风防御】停止加杠杆，切换高股息价值股 |
| 👑 5 | 其他 | ✅【顺风做多】享受流动性与汇率双重溢价 |

其中 `max_sev` = 除目的地外其余三国 severity 的最大值。

## 九、使用建议

1. **先选目的地**，再看四条曲线。目的地那一条会被隐藏（画 `na`），这是正常的。
2. **severity 的符号是关键**：负值表示海外经风险调整后收益更高，资金有流入动机；正值表示留在本地更划算。
3. **做跨国配置前**，先看「总计利息压力」与「近期趋势」两行，确认目标国债务周期不是处于恶化通道。
4. **裸敞口状态为 🚨 或 🟠 时**，不要只盯利息——汇率已经把收益吃光了。

## 十、已知问题与限制

1. **无告警函数**：脚本既没有 `alertcondition` 也没有 `alert()` 调用，**无法在 TradingView 中创建任何自动化警报**，只能人工盯盘。
2. **欧洲用德国代理**：欧元区 10Y / 2Y 分别固定为 `TVC:DE10Y` / `TVC:DE02Y`，意大利、希腊等周边国家利差被忽略，欧洲的利息压力会被**系统性低估**。
3. **固定请求日线**：`f_secure_req` 使用 `timeframe.period`（图表周期），而 `f_get_econ` 固定 `"1D"`。在小时线图上两者周期不一致，读数会失真，**建议在日线及以上使用**。
4. **债务惩罚为线性模型**：`k × max(0, debt − threshold)` 是简化假设，未区分内/外债、本/外币计价、债务久期结构。
5. **历史深度有限**：宏观序列起始时间较晚，图表拉到很早年份会出现空白。
6. **`precision=2`**：看板与数据窗口数值仅保留 2 位小数，观察小幅变动时不适用。
