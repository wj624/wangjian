# AA流动性压力指数（宏观分析）

> **Pine Script v6** · 副图指标（独立于价格图下方）
> 脚本声明：`indicator("流动性压力指数", shorttitle="流动性压力85版", overlay=false)`
> 当前版本：**V85**（2026-11-21）· 变更内容见「九、版本记录」

---

## 一、这个指标解决什么问题

它是一台**美元体系的「底层水温计」与系统性风险雷达**。

普通技术指标看的是价格，本脚本看的是**价格背后真正的燃料——美元流动性**。它通过抓取美联储与全球主要央行的资产负债表、隔夜回购市场利率、银行准备金等「管道级」数据，回答三个问题：

1. 美元体系内部**管道是否堵塞**（LSI 压力指数）
2. 全球央行**总水池是在放水还是抽水**（GLI 总量 + 三渠道流向雷达）
3. 当前处于哪种**极端宏观状态**（黑洞 / 滞胀 / 泛滥 / 范式转换）

**适用场景**：判断系统性风险、决定权益仓位上限、识别真正的顶部/底部宏观背景。**不用于日内开平仓**。

## 三、核心计算逻辑（代码说明）

### 3.1 LSI 内部压力指数（核心中的核心）

```pine
lsi = (sofr - rrp_rate) + (effr - iorb)
```

所有收益率原始值单位为**百分比**，脚本统一 `*100` 转成**基点(bps)**：

| 变量 | 数据源 | 含义 |
|---|---|---|
| `sofr` | `FRED:SOFR` | 担保隔夜融资利率（回购市场实际成交价） |
| `rrp_rate` | `FRED:RRPONTSYAWARD` | 隔夜逆回购**利率**（美联储给的地板） |
| `effr` | `FRED:EFFR` / `FRED:DFF` | 有效联邦基金利率 |
| `iorb` | `FRED:IORB` | 准备金余额利率（美联储给的天花板） |

**读法**：
- `SOFR − RRP利率` ＝ 私人市场借钱成本相对「把钱存美联储」的溢价 → **越大说明市场越缺美元**
- `EFFR − IORB` ＝ 银行间拆借相对准备金利率的偏离 → **为正说明银行体系开始抢钱**

**阈值（默认）**：

| 变量 | 默认值 | 含义 |
|---|---|---|
| `threshold_tight` | 20.0 bps | LSI 偏紧 |
| `threshold_extreme_tight` | 50.0 bps | LSI 极端紧张 |
| `threshold_extreme_loose` | −30.0 bps | LSI 极端宽松 |

### 3.2 GLI 全球流动性总量

```pine
total_liq = (fed_bal - tga_bal - rrp_bal
           + (ecb_bal_raw * eur_usd)
           + (pbc_bal_raw * cny_usd)
           + (boj_bal_raw * jpy_usd)) / 1e12
```

- 分子前三项：美联储总资产 − TGA（财政部一般账户）− RRP（逆回购）＝ **真正流入市场的净美元**
- 后三项：欧央行 / 中国人民银行 / 日本央行资产规模按汇率折算成美元
- 分母 `1e12`：统一换算成**万亿美元 (Trillion)** 量纲

高低位判定用 250 日百分位（`gli_lookback`）：>75 分位＝总量宽松，<25 分位＝总量收缩。

### 3.2.1 流动性冲量（二阶导数）

```pine
total_liq_change = (total_liq - prev_liq) / max(|prev_liq|, 0.01) * 100
liq_impulse      = nz(total_liq_change) - nz(total_liq_change[gli_mom_lookback])
```

即「变化率的变化率」——扩张**加速度**。连续 3 日回落（`ta.falling(liq_impulse, 3)`）＝动能衰竭预警。

### 3.3 RRP 枯竭与准备金红线

```pine
rrp_pct = rrp_trillion / ta.highest(rrp_trillion, 500) * 100
is_rrp_exhausted = (rrp_pct < 5.0) or (rrp_trillion < 0.1)
```

采用**双判据**兼容新旧时代：
- 相对判据：跌破近 500 日峰值的 **5%**（兼容后疫情 2.5T 巨量时代）
- 绝对判据：绝对值跌破 **0.1T**（兼容 2008 / 2018 低量时代）

准备金不足需**同时**满足两项（默认各 11%）：

```pine
is_reserve_low_gdp      = (准备金 / GDP)       < 0.11
is_reserve_low_assets   = (准备金 / 银行总资产) < 0.11
is_reserve_insufficient = is_reserve_low_gdp and is_reserve_low_assets
```

> 💡 代码中有专门注释处理 `FRED:GDP` 与 `FRED:WRBWFRBL` 的量纲问题：若 `gdp_raw > 1e11` 直接对齐，避免再乘 1000 把 GDP 放大千倍导致比率恒小于 11%。

### 3.4 收益率曲线斜率（危机捕获）

先对 10Y / 2Y / 利差各取 `ta.sma(…, 3)` 平滑，再与 `curve_lookback`（默认 10 天）前比较：

| 状态 | 判定式 | 含义 |
|---|---|---|
| 牛陡（衰退前兆） | 利差走阔 > 10bp **且** 2Y 下跌 ≥ 20bp | 市场恐慌抢跑降息，硬着陆定价 |
| 熊陡（杀估值） | 利差走阔 > 10bp **且** 10Y 上涨 ≥ 20bp | 期限溢价爆表，长久期资产杀估值 |
| 深度倒挂 | 10Y−2Y < −50bp | 中长期衰退引力 |
| 浅度倒挂 | 10Y−2Y < 0 | 观察修复路径 |
| 平稳正斜率 | 其他 | 期限结构常态化 |

### 3.5 三渠道资金流向雷达

分别计算 TGA(`FRED:WDTGAL`)、外国逆回购池(`FRED:WLRRAL`)、国内逆回购(`FRED:RRPONTSYD`) 在 `flow_lookback`（默认 10 天）内的变动，单位 **十亿美元 (B)**：

```pine
max_drain  = max(delta_tga_b, delta_wlrr_b, delta_rrp_b)   // 最大抽水
min_inject = min(delta_tga_b, delta_wlrr_b, delta_rrp_b)  // 最大放水
```

超过 `flow_threshold`（默认 5B）才判定为「有效动作」。文字三态：抽水＝红、放水＝绿、同时发生按净力量对比、否则＝白。

> ⚠️ 代码注释强调：这里特意用 `raw_rrp_b` 独立计算逆回购流向，并在 `nz()` 中传入当前值，**防止首根 K 线空值引发千亿级假抽水**。

### 3.6 辅助监控

| 模块 | 逻辑 |
|---|---|
| 强美元潮汐 | `DXY > MA(DXY, 50)` |
| 信用利差动量 | `ta.roc(credit_spread, 10) > 10%` |
| 市场广度 S5TH | 标普500 站上 200 日均线占比；弱化 <80%、严重 <60%、过热 ≥80%、底部 ≤15.5% |
| 金银比 GSR | `GOLD / SILVER`；≤50 偏低（黄金相对低估），≥80 偏高 |
| 美联储救市脉冲见顶 | TGA + 准备金归一化后各 50% 加权，跌破 MA(10) |

### 3.7 五种宏观状态

| 状态 | 判定式 |
|---|---|
| ⭐ 流动性黑洞 | 核心流动性断裂 **且** 信用利差 > 400bp **且** DXY 站上 50 日均线 |
| ⭐ 滞胀式危机 | 实际利率 > 1.8% **且** 信用利差 > 4.0% **且** 10Y 通胀预期 > 2.5% |
| ⭐ 流动性泛滥 | GLI 总量宽松 **且** DFII10 < 0% **且** 信用利差 < 350bp |
| ⭐ 范式转换 | 通胀预期偏差 > 0.9% **且** 金银比 ≤ 50 **且** 有效利率低于通胀 |
| ⭐ 风平浪静 | 以上皆不满足 |

其中 `is_liquidity_break = (lsi > 20bp) and is_rrp_exhausted`。

背景色仲裁优先级（后绘制覆盖先绘制，故**后者优先显示**）：
`美联储黄金到顶` > `危机触发` > `黄金到顶` > `滞胀+信用双杀` > `通胀预期偏差大` > `实际利率极宽` > `实际利率紧缩` > `S5TH严重` > `S5TH弱化` > `金银比高` > `金银比低` > `准备金不足` > `GLI总量收缩` > `QE总量宽松` > `利差动量飙升` > `曲线熊陡` > `曲线牛陡` > `动能衰竭` > `流动性周环比暴跌` > `强美元潮汐` > `RRP枯竭` > `核心流动性断裂` > `范式转换` > `流动性泛滥` > `滞胀式危机` > `流动性黑洞`

> ⚠️ **重要提醒**：因为后绘制的覆盖先绘制的，**背景色只代表优先级最高的那一层**，不等于"只有这一个状态在报警"。务必结合看板第 4 行的状态串一起看。

### 4.3 行 0：核心水位四格（最重要的一行）

#### 4.3.1 LSI 压力（第 1–2 列）

- **显示格式**：`LSI 压力 │ 34.7 BP`（数据缺失时右侧显示 `N/A`）
- **它是什么**：`LSI = (SOFR − RRP利率) + (EFFR − IORB)`，全部换算成**基点(bp)**，1 bp = 0.01%。
- **小白版理解**：把银行体系想成一个水池。
  - `SOFR − RRP利率`：银行在市场上借隔夜钱，比「把现金存回美联储拿利息」贵多少？贵得越多，说明外面越缺钱。
  - `EFFR − IORB`：银行之间互相借钱，比存美联储还贵多少？为正，说明已经开始抢钱。
  - 两项相加 = 管道内部的真实摩擦，**不看股价，只看钱贵不贵**。

| 读数（默认阈值） | 颜色 | 含义 |
|---|---|---|
| ≥ 50 bp | 深红（maroon） | 极端紧张，回购市场显著缺钱，随时可能出事故 |
| 20 – 50 bp | 红 | 偏紧，短端资金摩擦升温 |
| 0 – 20 bp | 白 | 中性平衡，管道正常 |
| < 0 bp | 绿 | 资金富余，钱比「存美联储」还便宜，宽松 |

- **常见误读**：
  1. 显示 `N/A` 不是「压力为 0」，而是 SOFR / RRP / EFFR / IORB **至少一路数据取不到**，此时脚本直接放弃判定（防呆），别当成安全信号。
  2. LSI 是**内部管道压力**，不含全球总量。LSI 低但总量在收缩，一样可能是逆风（看行 0 的 GLI 与行 3）。
  3. 单位是 bp，不是 %。看到 `34.7` 就是 0.347%，很窄的利差，但足以说明缺钱。

#### 4.3.2 GLI / 储备（第 3–4 列）

- **显示格式**：`6.32 / 3.10T`
  - 斜杠**前**＝ GLI 全球流动性总量（万亿美元），口径为：美联储总资产 − TGA − RRP + 欧央行 + 中国人民银行 + 日本央行（按汇率折美元）
  - 斜杠**后**＝ 美国银行体系准备金余额（万亿美元，数据源 `FRED:WRESBAL`）
- **小白版理解**：前半是「全球一共有多少水」，后半是「美国银行账户里真正能动的钱」。总水量大但准备金薄，说明水堵在别处（比如躺在美联储账上）。
- **颜色**：
  - 绿（lime）＝ 总量处于 250 日 **75 分位以上**，处于宽松高位
  - 近透明淡紫 ＝ 总量处于 250 日 **25 分位以下**，处于收缩低位（该配色用了 9/255 的透明度，实盘几乎看不见，见「八、已知问题」第 8 条）
  - 白 ＝ 介于两者之间，中性
- **核心源失联时**整格显示 `N/A(源失联)`，此时不要参考 GLI 相关判定。
- **常见误读**：GLI 是**总量**（全球），LSI 是**摩擦**（美国短端）。两者独立：总量充裕不代表管道不堵，管道通畅也不代表总量没在收缩。

#### 4.3.3 RRP 余额（第 5–6 列）

- **显示格式**：`25.54千亿 (1.02%)`
  - 第一个数字＝隔夜逆回购（ON RRP）余额，**单位自适应**：≥ 1 千亿显示「千亿」，< 1 千亿显示「亿」（如 `2.5亿`），避免读到 `0.0025千亿` 这种量级失效的写法
  - 括号里＝ **占历史峰值的百分比**（回看 2500 根日线 ≈ 10 年，覆盖 2022 年 2.5 万亿的峰值）
- **小白版理解**：RRP 是货币基金的「停车场」，也是银行体系的**安全气囊**。财政发债抽水时，钱先从 RRP 里出，不至于直接啃银行的准备金；RRP 见底，抽水就会直接打穿准备金。
- **枯竭判据（双轨，任一成立即判枯竭）**：占峰值 < 5% **或** 绝对余额 < 0.1 万亿。
- **颜色**：红＝枯竭；绿＝仍有缓冲；灰＝数据缺失。
- **常见误读**：RRP 很小并不等于危机，但意味着**以后没有缓冲垫**了，同样的抽水量杀伤力会成倍上升。

#### 4.3.4 US02Y / 利差（第 7–8 列）

- **显示格式**：`4.12 / 0.18`
  - 前半＝ 美国 2 年期国债收益率（**单位是 %，不是 bp**）
  - 后半＝ `|US02Y − EFFR|`，2 年期与政策利率的绝对偏离（百分点）
- **小白版理解**：2 年期代表市场对「未来两年政策利率」的定价。2Y 明显高于 EFFR，说明市场在押注**加息 / 更长时间维持高利率**；低于 EFFR，说明在押注**降息**。
- **颜色**：2Y > EFFR ＝ 红（偏鹰、紧缩预期）；否则绿。
- **常见误读**：后半是**绝对差**，看不出方向，方向要自己去比前后两个数字的大小。

### 4.4 行 1：四个利率 / 利差对照格

#### 4.4.1 SOFR / RRP（第 1–2 列）

- **显示**：`4.35 / 4.30`，单位 %，两个都是**利率**。
- **读法**：左边是回购市场实际成交价，右边是美联储给的地板价。两值相减为负 → 短端资金富余，银行宁可在市场借也不去 RRP；正得越多越缺钱。
- **颜色**：差 < 0 绿；差 > 20 bp 红；其余白。

#### 4.4.2 EFFR / IORB（第 3–4 列）

- **显示**：`4.33 / 4.40`，单位 %。
- **读法**：`EFFR − IORB` 是银行间拆借相对准备金利率的偏离，三档判读：

| 差值 | 颜色 | 含义 |
|---|---|---|
| < −5 bp | 绿 | 资金富余，银行不急着找美联储 |
| −5 ~ −2 bp | 橙 | **由松转紧**的过渡带，最值得盯的预警区 |
| > −2 bp | 红 | 紧张，银行体系开始抢钱 |
| 任一数据缺失 | 灰 | 不判定 |

> 注意这是**三档**配色（绿 / 橙 / 红），橙色不是"正常"，而是"正在变紧"。

#### 4.4.3 通胀预 / 实（第 5–6 列）

- **显示**：`2.32% / 2.15%`
  - 前半＝ 10 年期盈亏平衡通胀（市场对未来 10 年通胀的预期，`T10YIE`）
  - 后半＝ 10 年期**实际**利率（`DFII10`，已扣通胀的「真实」资金成本）
- **读法**：前半是「市场怕不怕通胀」，后半是「无风险的真实回报有多高」。实际利率越高，越压制黄金、成长股、长久期资产。
- **颜色**：通胀预期 > 2.5% **或** 实际利率 > 2.2% → 红；否则白。

#### 4.4.4 信用 / 通胀（第 7–8 列）

- **显示**：`3.12% / 2.90%`，可能带 ` (🔥急升)` 后缀
  - 前半＝ 美国高收益债（垃圾债）信用利差，**400 bp = 4.00% 为警戒线**
  - 后半＝ CPI 同比（现实通胀）
  - 后缀 `🔥急升` ＝ 信用利差在近 10 个交易日的 ROC 涨幅超过 10%
- **读法**：前半是企业借钱的「风险溢价」，涨得越快说明再融资环境恶化越快；后半是现实中物价涨多快。
- **颜色**：利差 > 4.00% **或** CPI > 3.0% **或** 触发急升 → 红；否则白。
- **常见误读**：利差绝对水平不高但带 `🔥急升` 时同样危险，这是"动量警报"，早于绝对水位破线。

### 4.5 行 2：动能、广度、曲线结构

#### 4.5.1 流动性冲量（第 1–2 列）

- **显示**：`-0.12%`，动能衰竭时追加 ` ⚠`
- **算法**：`GLI 周环比变化率 − 该变化率 20 天前的值`，即**加速度**（二阶导）。
- **读法**：> 0 = 放水在「加速」；≤ 0 = 放水在「减速」。连续 3 期回落 → 标 `⚠`，意味着推力衰竭（价格可能还在涨，但燃料在减少）。
- **颜色**：> 0 绿（lime）；≤ 0 橙。
- **常见误读**：冲量正不代表总量高。总量可能在高位但冲量转负，这叫「高位钝化」，是最容易套人的阶段。

#### 4.5.2 S5TH 广度（第 3–4 列）

- **显示**：`62.3%`
- **含义**：标普 500 成分股中，站上 200 日均线的股票占比。衡量「指数上涨是不是多数股票一起涨」。
- **颜色**：

| 条件 | 颜色 | 含义 |
|---|---|---|
| < 60% | 红 | 广度严重崩坏，多数股票跌破年线，指数内部空头主导 |
| < 80% 且 5/20/50 日均线空头排列 | 橙 | 广度弱化 + 均线死叉，赚钱效应收缩 |
| 其他 | 白 | 未触发阈值，需结合行 5 三阶文案看是否过热 / 底部 |

- **附加阈值**：≥ 80% 视为「经济过热度偏高」、≤ 15.5% 视为「极端底部」，这两条只在行 4 标签与行 5 文案里体现，**不改本格颜色**。

#### 4.5.3 曲线 / 斜率预警（第 5–8 列，合并）

- **显示格式**：`状态 ±xxbp ｜ 预警文案`，例如 `深度倒挂 -89bp ｜ 无极端结构异动`
- **三段含义**：① 曲线状态定性 → ② 10Y−2Y 利差当期值（bp）→ ③ 斜率突变结论
- **状态与颜色（五档）**：

| 状态文案 | 颜色 | 触发条件（默认） |
|---|---|---|
| 牛陡(衰退前兆) | 红 | 10 天内利差走阔 > 10 bp，且 2Y 下跌 ≥ 20 bp（市场抢跑降息 / 硬着陆恐慌） |
| 熊陡(杀估值) | 橙 | 10 天内利差走阔 > 10 bp，且 10Y 上涨 ≥ 20 bp（长端失控，折现率上行杀估值） |
| 深度倒挂 | 黄 | 利差 < −50 bp |
| 浅度倒挂 | 灰 | −50 bp ≤ 利差 < 0 |
| 平稳正斜率 | 绿 | 利差 ≥ 0 |

- **预警文案（第三段）只有三种**：`⚠衰退/流动性枯竭前兆`（牛陡）、`⚠长端通胀/结构杀估值`（熊陡）、`无极端结构异动`。
- **常见误读**：「无极端结构异动」只表示**斜率没有突变**，不代表曲线健康——深度倒挂时也会显示「无极端结构异动」，倒挂本身看前面的状态词。

#### 4.6.4 残差归因段（第三段，仅超容忍时出现）

残差 = 三渠道净抽水 − 准备金实际减少量。它回答：「三渠道算出来的抽水，和准备金实际掉的钱对不上，差在哪？」

| 归因文案（关键词） | 触发条件 | 人话与用法 |
|---|---|---|
| `准备金周度序列(WRESBAL)近N根bar未刷新…假信号` | 准备金序列 10 根 bar 内几乎没变 | 数据还没更新，残差是时点错配造成的**假信号**，先别采信 |
| `资产端校验命中：Fed总资产(WALCL)近20bar收缩…缩表(QT)到期不续买…` | 残差为负且资产端收缩足以覆盖 | 真凶是缩表，三渠道口径本身有效，抽水是真的 |
| `TGA释放…但准备金未同步增加…属财政投放未落地、钱停在美联储账上` | 残差为负 + TGA 在放水 | **账面净放水但没进银行体系**，不能当真实注入给风险资产定价 |

| `准备金实际减少量少于三渠道合计，Fed其他负债项反向释放…对冲` | 残差为正 | 抽水被别的负债项对冲了，实际抽水强度要打折 |

#### 4.6.5 一个完整示例（数据仅用于演示读法）

> `买方: 货基吸金[Bill-OIS -26.3bp] ｜ 卖方: 净放水698.3亿 ｜TGA放52.8亿 RRP持平 外回购放17.0亿 准备金减121.5亿 ⚠残差放水未落地527.8亿 ｜资产端缩表121.5亿[缩表抽水] ｜残差归因: TGA释放528.4亿…缺口406.3亿归Fed其他负债项…`

逐段翻译：
1. **买方**：货基在抢短债，短债收益率被买到低于 SOFR 26.3 bp —— 资金停在短端，没外溢到风险资产。
2. **卖方**：三渠道账面净放水 698.3 亿（TGA 放 528.4 亿、RRP 没动、外回购放 170.4 亿）。
3. **但是**：准备金实际还减少了 121.5 亿，与「放水」方向相反 → 残差 527.8 亿，标 `放水未落地`。
4. **资产端**：同期美联储缩表 121.5 亿，量级刚好能解释准备金流失 → 标 `[缩表抽水]`。
5. **结论**：这周是**名义放水、实际偏紧**：钱从财政账户出来又被 Fed 的缩表和其他负债项吸走，真正进到银行体系的极少。看到「净放水」三个字就兴奋，是这一行最常见的错误。

### 4.7 行 4：宏观状态串（整行，先看这一行）

#### 4.7.1 结构

```text
[⚠周期提示]  ⭐【宏观状态】<主状态>  ➔  <子标签1> | <子标签2> | <子标签3> …
```

- **前置 `⚠当前周期 xx 非日线…`**：只有在非日线图表上才出现，提示日度环比与分位读数会失真。
- **`⭐【宏观状态】` 后面只有 7 种可能**（按优先级从高到低，命中即停）：流动性黑洞 → 滞胀式危机 → 衰退前兆(极速牛陡) → 长端崩盘(极速熊陡) → 流动性泛滥 → 范式转换 → 风平浪静。
- **`➔` 之后**：第一个标签**永远是 LSI 档位**（5 选 1），后面是所有同时成立的其它告警，可能很长。
- **文字颜色**：有任一严重告警＝**橙色**；否则白色。**底色**：黑天鹅级（黑洞/断裂/危机）＝深红；其它告警＝暗橙；常态＝不填色。

#### 4.7.2 七种主状态（触发条件）

| 主状态 | 触发条件（默认口径） | 含义 |
|---|---|---|
| ⭐【流动性黑洞】 | LSI ≥ 20 且 RRP 枯竭 且 信用利差 > 400bp 且 美元指数在 50 日均线上方 | 短期债务周期严重去杠杆，风险溢价被无差别抛售 |
| ⭐【滞胀式危机】 | 实际利率 > 1.8% 且 信用利差 > 400bp，并且 10Y 通胀预期 > 2.5% | 通胀顽固 + 实体信用恶化共振，股债双杀 |
| 🚨【衰退前兆(极速牛陡)】 | 同 4.5.3 的牛陡条件 | 市场恐慌性抢跑降息与硬着陆 |
| 🚨【长端崩盘(极速熊陡)】 | 同 4.5.3 的熊陡条件 | 长端失控，长久期资产杀估值 |
| ⭐【流动性泛滥】 | 总量宽松 且 实际利率 < 0 且 信用利差 < 350bp | 绝对扩张象限，资产价格重估 |

| ⭐【宏观状态】风平浪静 | 以上都不成立 | 没有系统性极端，风险在个体层面 |

#### 4.7.3 `➔` 之后的子标签全表

**① 必有一个的 LSI 档位**（5 选 1）：`⚠LSI极端紧张` / `⚠LSI偏紧` / `LSI极端宽松` / `LSI正常宽松` / `LSI平衡/中性`

**② 状态级（⭐，与主状态同步出现）**：`⭐【流动性黑洞】`、`⭐【滞胀式危机】`、`⭐【流动性泛滥】`、`⭐【范式转换】`

**③ 核心断裂与缓冲垫**

| 标签 | 触发条件 | 含义 |
|---|---|---|
| `⚠核心流动性断裂` | LSI ≥ 20 且 RRP 枯竭 | 管道断裂，最严重的一档 |

**⑤ 利率与通胀（价格端）**

| 标签 | 触发条件 | 含义 |
|---|---|---|
| `⚠实际利率紧缩` | 10Y 实际利率 > 2.2% | 真实无风险回报高，压制成长与无息资产 |

### 4.8 行 5：AI 四维分析（整行）

四段固定用 ` ｜ ` 连接（开启 `AI 四段合并为单条流` 后进一步串成一条流水文本）：

| 段 | 标签开头 | 回答的问题 |
|---|---|---|
| 1 | `🩸【资金去向】` | 买方是谁、卖方抽放多少、残差是否闭合（内容与行 3 同源，但写成完整句子） |
| 2 | `【一阶宏观周期与债务周期】` | 现在处在周期的哪个阶段，该配什么，以及实际利率 / 通胀偏差 / 强美元 / 贵金属的叠加约束 |
| 3 | `【二阶流动性矩阵与底层水位】` | 全球总量 + LSI 内部管道 + RRP 缓冲垫 + 准备金红线 + 冲量加速度的综合判断 |
| 4 | `【三阶微观定价与风险溢价】` | 曲线结构 + 信用利差高度与动量 + S5TH 广度 + 短债定价扭曲 |

- **文字颜色**：淡蓝（`rgb(190,234,255)`），与行 4 的橙色告警区分开。
- **每段内部的 `[...]` 方括号**是**触发项摘要**，例如 `[实际利率紧缩]`、`[财政投放未落地]`、`[短端供给压力]`——方括号是"命中了哪条规则"，方括号外的句子是"这条规则意味着什么"。
- **极简视图下**该行显示：`极简视图：AI 四维分析已折叠(切回「标准」查看)；水位与告警见上方各行。`（省纵向空间，信息源不丢）
- **常见误读**：AI 四段是**规则引擎按条件拼装的文本**，不是大模型自由发挥；同一输入必然得到同一输出，可复盘、可回测。

## 附录：为什么 EFFR 与 US02Y 贴近通胀预期/实际收益率、同时信用利差上升，意味着衰退？

> 本节内容整理自原 `AAA/README.MD`，保留存档。

这种现象描述的是宏观金融环境进入了**「流动性陷阱」与「信用收缩」共振**的极高风险阶段。可以从政策利率的有效性边界、实体融资成本的背离、银行体系的传导失效三个维度拆解。

### 1. 政策利率触及「名义锚定陷阱」

当 EFFR（有效联邦基金利率）和 US02Y（两年期国债收益率）持续下降，并开始贴近 10YIE（损益平衡通胀率）和 DFII10（10 年期实际收益率）时，意味着：

- **降息空间的「硬约束」**：名义利率正在逼近通胀预期。如果名义利率低于通胀预期，理论上实际利率为负，这通常是衰退后期的极度刺激手段。但在衰退前期，这种贴近意味着市场认为美联储已经快要「打光子弹」，或者政策放松的速度已经赶不上经济基本面恶化的速度。
- **增长预期的坍塌**：US02Y 贴近 10 年期实际收益率（DFII10），暗示市场对短期增长的预期已经降至长期潜在增长率以下，甚至认为短期内没有任何增长溢价。

### 2. 「信用剪刀差」：政策宽松与融资难的背离

这是衰退最核心的信号。通常美联储降息是为了降低实体经济的借贷成本，但如果信用利差在这个过程中反而上升，就会发生：

- **传导机制断裂**：尽管无风险利率（国债收益率）在下降，但由于风险偏好极度萎缩，企业债、房贷等风险资产的溢价飙升。结果是基准利率在降，但企业的实际融资成本反而上升。
- **避险情绪主导**：资金正在进行「存量博弈」，疯狂涌入国债对冲风险（推低 US02Y），同时大规模抛售公司债（推高利差）。这种「风险资产与无风险资产的剧烈撕裂」是金融体系对衰退的提前定价。

### 3. 银行净息差（NIM）挤压与信用螺旋

这种利率结构对银行信贷供给是致命的：

- **负债端「地板」效应**：存款利率存在名义零下限（ZLU），当市场利率持续下降时，银行很难进一步降低付息成本。
- **资产端收益缩水**：贷款利率随 US02Y 下行，导致利差（NIM）极度收窄。
- **放贷意愿归零**：当「微薄的利润」无法覆盖「上升的信用风险」时，银行会主动收缩资产负债表。这种信用紧缩（Credit Crunch）会直接切断实体经济的流动性，导致经济从「增长放缓」迅速跌入「衰退」。

**总结**：当这种场景发生时，市场实际上在向美联储传递一个绝望的信息——「你降息是为了救市，但市场因为害怕衰退而不再相信信用。你给的流动性都淤积在国债里，而真正需要钱的企业却因为利差飙升而死掉。」
