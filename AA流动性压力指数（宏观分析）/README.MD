# AA流动性压力指数（宏观分析）

> **Pine Script v6** · 副图指标（独立于价格图下方）
> 脚本声明：`indicator("流动性压力指数", shorttitle="流动性压力61版", overlay=false)`

---

## 一、这个指标解决什么问题

它是一台**美元体系的「底层水温计」与系统性风险雷达**。

普通技术指标看的是价格，本脚本看的是**价格背后真正的燃料——美元流动性**。它通过抓取美联储与全球主要央行的资产负债表、隔夜回购市场利率、银行准备金等「管道级」数据，回答三个问题：

1. 美元体系内部**管道是否堵塞**（LSI 压力指数）
2. 全球央行**总水池是在放水还是抽水**（GLI 总量 + 三渠道流向雷达）
3. 当前处于哪种**极端宏观状态**（黑洞 / 滞胀 / 泛滥 / 范式转换）

**适用场景**：判断系统性风险、决定权益仓位上限、识别真正的顶部/底部宏观背景。**不用于日内开平仓**。

## 三、核心计算逻辑（代码说明）

### 3.1 LSI 内部压力指数（核心中的核心）

```pine
lsi = (sofr - rrp_rate) + (effr - iorb)
```

所有收益率原始值单位为**百分比**，脚本统一 `*100` 转成**基点(bps)**：

| 变量 | 数据源 | 含义 |
|---|---|---|
| `sofr` | `FRED:SOFR` | 担保隔夜融资利率（回购市场实际成交价） |
| `rrp_rate` | `FRED:RRPONTSYAWARD` | 隔夜逆回购**利率**（美联储给的地板） |
| `effr` | `FRED:EFFR` / `FRED:DFF` | 有效联邦基金利率 |
| `iorb` | `FRED:IORB` | 准备金余额利率（美联储给的天花板） |

**读法**：
- `SOFR − RRP利率` ＝ 私人市场借钱成本相对「把钱存美联储」的溢价 → **越大说明市场越缺美元**
- `EFFR − IORB` ＝ 银行间拆借相对准备金利率的偏离 → **为正说明银行体系开始抢钱**

**阈值（默认）**：

| 变量 | 默认值 | 含义 |
|---|---|---|
| `threshold_tight` | 20.0 bps | LSI 偏紧 |
| `threshold_extreme_tight` | 50.0 bps | LSI 极端紧张 |
| `threshold_extreme_loose` | −30.0 bps | LSI 极端宽松 |

### 3.2 GLI 全球流动性总量

```pine
total_liq = (fed_bal - tga_bal - rrp_bal
           + (ecb_bal_raw * eur_usd)
           + (pbc_bal_raw * cny_usd)
           + (boj_bal_raw * jpy_usd)) / 1e12
```

- 分子前三项：美联储总资产 − TGA（财政部一般账户）− RRP（逆回购）＝ **真正流入市场的净美元**
- 后三项：欧央行 / 中国人民银行 / 日本央行资产规模按汇率折算成美元
- 分母 `1e12`：统一换算成**万亿美元 (Trillion)** 量纲

高低位判定用 250 日百分位（`gli_lookback`）：>75 分位＝总量宽松，<25 分位＝总量收缩。

### 3.2.1 流动性冲量（二阶导数）

```pine
total_liq_change = (total_liq - prev_liq) / max(|prev_liq|, 0.01) * 100
liq_impulse      = nz(total_liq_change) - nz(total_liq_change[gli_mom_lookback])
```

即「变化率的变化率」——扩张**加速度**。连续 3 日回落（`ta.falling(liq_impulse, 3)`）＝动能衰竭预警。

### 3.3 RRP 枯竭与准备金红线

```pine
rrp_pct = rrp_trillion / ta.highest(rrp_trillion, 500) * 100
is_rrp_exhausted = (rrp_pct < 5.0) or (rrp_trillion < 0.1)
```

采用**双判据**兼容新旧时代：
- 相对判据：跌破近 500 日峰值的 **5%**（兼容后疫情 2.5T 巨量时代）
- 绝对判据：绝对值跌破 **0.1T**（兼容 2008 / 2018 低量时代）

准备金不足需**同时**满足两项（默认各 11%）：

```pine
is_reserve_low_gdp      = (准备金 / GDP)       < 0.11
is_reserve_low_assets   = (准备金 / 银行总资产) < 0.11
is_reserve_insufficient = is_reserve_low_gdp and is_reserve_low_assets
```

> 💡 代码中有专门注释处理 `FRED:GDP` 与 `FRED:WRBWFRBL` 的量纲问题：若 `gdp_raw > 1e11` 直接对齐，避免再乘 1000 把 GDP 放大千倍导致比率恒小于 11%。

### 3.4 收益率曲线斜率（危机捕获）

先对 10Y / 2Y / 利差各取 `ta.sma(…, 3)` 平滑，再与 `curve_lookback`（默认 10 天）前比较：

| 状态 | 判定式 | 含义 |
|---|---|---|
| 牛陡（衰退前兆） | 利差走阔 > 10bp **且** 2Y 下跌 ≥ 20bp | 市场恐慌抢跑降息，硬着陆定价 |
| 熊陡（杀估值） | 利差走阔 > 10bp **且** 10Y 上涨 ≥ 20bp | 期限溢价爆表，长久期资产杀估值 |
| 深度倒挂 | 10Y−2Y < −50bp | 中长期衰退引力 |
| 浅度倒挂 | 10Y−2Y < 0 | 观察修复路径 |
| 平稳正斜率 | 其他 | 期限结构常态化 |

### 3.5 三渠道资金流向雷达

分别计算 TGA(`FRED:WDTGAL`)、外国逆回购池(`FRED:WLRRAL`)、国内逆回购(`FRED:RRPONTSYD`) 在 `flow_lookback`（默认 10 天）内的变动，单位 **十亿美元 (B)**：

```pine
max_drain  = max(delta_tga_b, delta_wlrr_b, delta_rrp_b)   // 最大抽水
min_inject = min(delta_tga_b, delta_wlrr_b, delta_rrp_b)  // 最大放水
```

超过 `flow_threshold`（默认 5B）才判定为「有效动作」。文字三态：抽水＝红、放水＝绿、同时发生按净力量对比、否则＝白。

> ⚠️ 代码注释强调：这里特意用 `raw_rrp_b` 独立计算逆回购流向，并在 `nz()` 中传入当前值，**防止首根 K 线空值引发千亿级假抽水**。

### 3.6 辅助监控

| 模块 | 逻辑 |
|---|---|
| 强美元潮汐 | `DXY > MA(DXY, 50)` |
| 信用利差动量 | `ta.roc(credit_spread, 10) > 10%` |
| 市场广度 S5TH | 标普500 站上 200 日均线占比；弱化 <80%、严重 <60%、过热 ≥80%、底部 ≤15.5% |
| 金银比 GSR | `GOLD / SILVER`；≤50 偏低（黄金相对低估），≥80 偏高 |
| 美联储救市脉冲见顶 | TGA + 准备金归一化后各 50% 加权，跌破 MA(10) |

### 3.7 五种宏观状态

| 状态 | 判定式 |
|---|---|
| ⭐ 流动性黑洞 | 核心流动性断裂 **且** 信用利差 > 400bp **且** DXY 站上 50 日均线 |
| ⭐ 滞胀式危机 | 实际利率 > 1.8% **且** 信用利差 > 4.0% **且** 10Y 通胀预期 > 2.5% |
| ⭐ 流动性泛滥 | GLI 总量宽松 **且** DFII10 < 0% **且** 信用利差 < 350bp |
| ⭐ 范式转换 | 通胀预期偏差 > 0.9% **且** 金银比 ≤ 50 **且** 有效利率低于通胀 |
| ⭐ 风平浪静 | 以上皆不满足 |

其中 `is_liquidity_break = (lsi > 20bp) and is_rrp_exhausted`。

背景色仲裁优先级（后绘制覆盖先绘制，故**后者优先显示**）：
`美联储黄金到顶` > `危机触发` > `黄金到顶` > `滞胀+信用双杀` > `通胀预期偏差大` > `实际利率极宽` > `实际利率紧缩` > `S5TH严重` > `S5TH弱化` > `金银比高` > `金银比低` > `准备金不足` > `GLI总量收缩` > `QE总量宽松` > `利差动量飙升` > `曲线熊陡` > `曲线牛陡` > `动能衰竭` > `流动性周环比暴跌` > `强美元潮汐` > `RRP枯竭` > `核心流动性断裂` > `范式转换` > `流动性泛滥` > `滞胀式危机` > `流动性黑洞`

> ⚠️ **重要提醒**：因为后绘制的覆盖先绘制的，**背景色只代表优先级最高的那一层**，不等于"只有这一个状态在报警"。务必结合看板第 4 行的状态串一起看。

## 四、看板逐格解读（右上，8 列 × 6 行）

| 行 | 内容 |
|---|---|
| 0 | LSI 压力（bps，按阈值染色）· GLI 总量 / 银行准备金（T） |
| 1 | RRP 余额（T + 占峰值 %）· US02Y / 与 EFFR 差值 |
| 2 | SOFR / RRP 利率 · EFFR / IORB |
| 3 | 通胀预期 / 实际利率 · 信用利差 / 通胀 YoY |
| 4 | 流动性冲量（%）· S5TH 广度（%）· 资金去向（周） |
| 5 | 宏观状态串（自动折行，含主状态 ➔ 子告警） |
| 6 | AI 四维合成判断（资金动态 + 一阶周期 + 二阶水位 + 三阶定价） |

**AI 四维引擎**刻意不使用 `else-if` 盲区掩盖，而是「主象限 + 多因子叠加」实时定量归因：

- **资金动态**：三渠道净流量穿透（净抽水 / 净放水 / 平衡）
- **一阶宏观周期与债务周期**：主周期定性 + 实际利率 / 通胀偏差 / 强美元 / 贵金属周期叠加
- **二阶流动性矩阵与底层水位**：全球总量 + LSI 内部管道 + RRP 缓冲垫 + 准备金 + 冲量加速度
- **三阶微观定价与风险溢价**：美债曲线结构 + 信用利差高度与动量 + S5TH 广度

## 八、已知问题与限制

1. **背景色叠加覆盖**（最重要）：见上文 3.7。多个状态同时成立时，只显示优先级最高的颜色，必须以看板文字为准。
2. **美国口径数据**：信用利差 `BAMLH0A0HYM2`、通胀 `USIRYY`、`DFII10` 均为美国数据，不随标的切换。
3. **无 `alertcondition`**：脚本未声明任何告警条件，无法创建 TradingView 自动化警报，只能人工盯盘。
4. **宏观数据低频**：FRED 序列多为周 / 月频，日线图上表现为阶梯状「粘值」，属正常现象。
5. **单位混用**：LSI / 信用利差内部为 bps，`th_*` 输入为百分比，代码统一 `*100` 换算，二次开发需留意。
6. **历史长度依赖**：`ta.percentile_linear_interpolation(total_liq, 250, …)` 需要 ≥250 根日线历史，图表过短时该值为 `na`。
7. **死变量**：`wdtgal` 的 `ta.lowest/highest` 等部分中间量仅用于归一化，不直接输出。

## 附录：为什么 EFFR 与 US02Y 贴近通胀预期/实际收益率、同时信用利差上升，意味着衰退？

> 本节内容整理自原 `AAA/README.MD`，保留存档。

这种现象描述的是宏观金融环境进入了**「流动性陷阱」与「信用收缩」共振**的极高风险阶段。可以从政策利率的有效性边界、实体融资成本的背离、银行体系的传导失效三个维度拆解。

### 1. 政策利率触及「名义锚定陷阱」

当 EFFR（有效联邦基金利率）和 US02Y（两年期国债收益率）持续下降，并开始贴近 10YIE（损益平衡通胀率）和 DFII10（10 年期实际收益率）时，意味着：

- **降息空间的「硬约束」**：名义利率正在逼近通胀预期。如果名义利率低于通胀预期，理论上实际利率为负，这通常是衰退后期的极度刺激手段。但在衰退前期，这种贴近意味着市场认为美联储已经快要「打光子弹」，或者政策放松的速度已经赶不上经济基本面恶化的速度。
- **增长预期的坍塌**：US02Y 贴近 10 年期实际收益率（DFII10），暗示市场对短期增长的预期已经降至长期潜在增长率以下，甚至认为短期内没有任何增长溢价。

### 2. 「信用剪刀差」：政策宽松与融资难的背离

这是衰退最核心的信号。通常美联储降息是为了降低实体经济的借贷成本，但如果信用利差在这个过程中反而上升，就会发生：

- **传导机制断裂**：尽管无风险利率（国债收益率）在下降，但由于风险偏好极度萎缩，企业债、房贷等风险资产的溢价飙升。结果是基准利率在降，但企业的实际融资成本反而上升。
- **避险情绪主导**：资金正在进行「存量博弈」，疯狂涌入国债对冲风险（推低 US02Y），同时大规模抛售公司债（推高利差）。这种「风险资产与无风险资产的剧烈撕裂」是金融体系对衰退的提前定价。

### 3. 银行净息差（NIM）挤压与信用螺旋

这种利率结构对银行信贷供给是致命的：

- **负债端「地板」效应**：存款利率存在名义零下限（ZLU），当市场利率持续下降时，银行很难进一步降低付息成本。
- **资产端收益缩水**：贷款利率随 US02Y 下行，导致利差（NIM）极度收窄。
- **放贷意愿归零**：当「微薄的利润」无法覆盖「上升的信用风险」时，银行会主动收缩资产负债表。这种信用紧缩（Credit Crunch）会直接切断实体经济的流动性，导致经济从「增长放缓」迅速跌入「衰退」。

**总结**：当这种场景发生时，市场实际上在向美联储传递一个绝望的信息——「你降息是为了救市，但市场因为害怕衰退而不再相信信用。你给的流动性都淤积在国债里，而真正需要钱的企业却因为利差飙升而死掉。」
